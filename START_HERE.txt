P: Preciso ter Node.js instalado?
R: NÃO! É um site estático, funciona em qualquer navegador.

P: Quanto tempo leva para GitHub Pages atualizar?
R: 1-2 minutos normalmente. Se demorarm mais, limpe o cache (Ctrl+Shift+Del).

P: Onde encontro as melhores imagens?
R: Unsplash (https://unsplash.com/) - grátis e alta qualidade.

P: Posso mudar as imagens depois?
R: SIM! Simplesmente sobrescreva o ficheiro JPG e faça git push novamente.

P: E se as imagens não aparecerem?
R: Verifique:
   1. Estão na pasta certa? (images/[dia]/[pasta]/)
   2. Formato JPG? (não PNG ou GIF)
   3. Nomeadas corretamente? (img1.jpg, img2.jpg, etc)
   4. Fez git push? (git status para verificar)

P: Como posso testar em 3G/4G sem publicar?
R: Use http-server local:
   npm install -g http-server
   http-server -p 8000
   Depois abra: http://localhost:8000
