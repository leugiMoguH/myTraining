# 📥 Guia: Download e Organização de Imagens de Exercícios

Vou mostrar como fazer download de imagens de alta qualidade para o seu plano de treino.

## 🎯 Objetivo

Ter entre **3 e 6 imagens** por exercício, organizadas corretamente em pastas, para uma visualização melhor no telemóvel.

---

A estrutura de pastas já foi criada automaticamente:

## 💾 PASSO 4: Fazer Download e Organizar

### Passo a Passo:

1. **Abra a Unsplash**: https://unsplash.com/
2. **Procure o exercício**: Use a keyword da tabela acima
3. **Escolha a imagem**: Procure a melhor qualidade
4. **Clique em Download**: Botão verde no topo
5. **Renomeie a imagem**: 
   - Primeira imagem: `img1.jpg`
   - Segunda imagem: `img2.jpg`
   - Terceira imagem: `img3.jpg`
   - Etc...
6. **Mova para a pasta correta**: Ex: `images/segunda/img1/img1.jpg`

### Exemplo Prático:

```
🎯 Quer adicionar imagens para "Agachamento"

1. Vá a https://unsplash.com/
2. Procure por: "barbell squat"
3. Encontre 4 boas imagens
4. Faça download de cada uma
5. Renomeie:
   - squat_1.jpg → img1.jpg
   - squat_2.jpg → img2.jpg
   - squat_3.jpg → img3.jpg
   - squat_4.jpg → img4.jpg
6. Coloque em: images/quarta/imgagac/
   - images/quarta/imgagac/img1.jpg
   - images/quarta/imgagac/img2.jpg
   - images/quarta/imgagac/img3.jpg
   - images/quarta/imgagac/img4.jpg
```

## ✨ QUALIDADE: Critérios Importantes

Ao escolher imagens, verifique:

✅ **Resolução**: Mínimo 400x400px (preferencialmente 800x800+)
✅ **Foco**: Exercício bem visível no centro
✅ **Iluminação**: Imagem clara e bem iluminada
✅ **Sem Marca**: Sem watermarks ou logos visíveis
✅ **Formato**: JPG ou PNG
✅ **Realismo**: Técnica correta do exercício
✅ **Variedade**: Diferentes ângulos se possível

❌ **Evitar**: Imagens desfocadas, baixa qualidade, muito escuras

## ❓ Dúvidas Frequentes

**P: As imagens podem estar em diferentes orientações?**
R: Sim, o site foi otimizado para diferentes tamanhos e orientações. Recomenda-se consistência.

**P: Qual é o tamanho ideal de cada imagem?**
R: Entre 800x600 e 1200x800 é ideal. A qualidade é mais importante que o tamanho.

**P: Posso usar imagens de qualquer pessoa?**
R: Sim, desde que as imagens tenham licença Creative Commons ou similares. Unsplash e Pixabay garantem isso.

**P: Como faço para trocar uma imagem depois?**
R: Simplesmente sobrescreva o arquivo JPG e faça git push novamente.
